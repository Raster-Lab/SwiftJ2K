       swiftj2k - help, version and capability reporting for SwiftJ2K

DDEESSCCRRIIPPTTIIOONN
       This development tool provides help, version and truthful library
       capability reporting.  The library implements scalar lossless JPEG 2000
       Part 1 coding for unsigned greyscale images; the reserved encode,
       decode, inspect and validate commands and native transcode are not yet
       wired to it and return 4 without opening input, consuming standard
       input or creating output.  Build with Swift 6.2 or later (6.4
       qualified) in Swift 6 language mode. Apple OS minimum is 26.0.  CLI
       hosts are macOS and Linux; consult qualification records for executed
       coverage.

DDIIAAGGNNOOSSTTIICC LLEEVVEELLSS
       Default 0 reports errors only. Levels are cumulative: 1 summary; 2
       stages; 3 capability/configuration details; 4 elapsed timing; 5 bounded
       trace. Invalid levels or totals above 5 return 2.  Explicit levels set
       and repeated flags increment in argument order.  Diagnostics use
       stderr. Requested help/version/capability data uses stdout.  No payload
       bytes, metadata, raw addresses or input/output paths are logged.

RREESSEERRVVEEDD CCOODDEECC SSYYNNTTAAXX
       Codec command help lists reserved -i/--input, -o/--output, --input-
       format, --output-format, --mode, --max-error, --backend, --copy-policy,
       --threads, --max-memory, --timeout, --overwrite and --json.  These are
       not implemented payload operations. A single hyphen will denote
       standard input/output in a future codec command. Default future mode is
       lossless and copy policy is require-sharing. No private intermediate
       image format is implemented.

EEXXIITT SSTTAATTUUSS
       0 success/help/version; 2 invalid usage; 4 unsupported operation; 6
       output I/O failure including a closed pipe.  Future codec statuses
       reserve 3 malformed input, 5 resource/deadline, 7 internal failure and
       130 user cancellation.

IINNSSTTAALLLLAATTIIOONN
       Scripts/install-cli.sh installs or updates the executable and this page
       together.  Use --prefix for an absolute prefix (default /usr/local),
       --destdir or DESTDIR for staging, and --binary for a prebuilt binary
       matching VERSION.  Files are PREFIX/bin/swiftj2k and
       PREFIX/share/man/man1/swiftj2k.1.  For custom prefixes use man -M
       PREFIX/share/man swiftj2k, or configure MANPATH.  No index refresh is
       needed for direct lookup; no sudo runs automatically.
